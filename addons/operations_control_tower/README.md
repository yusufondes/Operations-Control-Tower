# Operations Control Tower 2.0

Odoo 19 application for tracking operational priorities, ownership, statuses, deadlines, and blockers.

## Included

- Control item model with business area, impact, owner, priority, deadline, next action, status, and overdue flag
- Automatic `OCT/00001`-style references
- Kanban, list, form, calendar, graph, pivot, and search views
- Separate user and manager roles with owner-based record rules
- Optional English demo records with dynamic deadlines
- Transaction tests for statuses, sequencing, security, and overdue calculation
