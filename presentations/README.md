# HALY business portfolio presentation

## Current sharing files

- [14-slide business case PDF](../docs/portfolio/HALY-Operations-Control-Tower-Business-Case-With-Company.pdf):
  English, selectable/searchable text, page bookmarks and a GitHub source link.
- [Editable PowerPoint](../docs/portfolio/HALY-Operations-Control-Tower-Business-Case-With-Company.pptx):
  native text, two editable tables, seven original evidence screenshots and
  per-slide speaker notes with sources and limitations.

Use this With-Company pair for sharing. Its first slide introduces HALY as a
fictional powdered-drink manufacturer, with a small illustrative packaging image.
The remaining slides cover the stock shortage, accepted dispatch dates,
date-first allocation, complete individual shipments, corporate backorders,
in-house manufacturing, owned exceptions and recorded test outcomes. Technology
is last. Readers do not need to install Odoo to understand the case.

The 81 local test methods and 11 campaign cases recorded on 15 October 2026 are
separate from the eight base-addon methods in GitHub CI. All company/customer
data is synthetic. No real-client result, measured ROI or production deployment
is claimed. Implementation, testing and review used AI assistance.

## Design and image provenance

The current deck uses a 16:9 white canvas, Calibri, charcoal text and a muted plum
accent. Evidence crops highlight actual synthetic Odoo records. Browser examples
remain separate from the complete 900-unit local test scenario.

The cover asset is
[haly-drink-mix-canisters.png](../docs/portfolio/assets/haly-drink-mix-canisters.png).
It was generated with the built-in image-generation tool on 16 October 2026,
without reference images. The brief requested two plain HALY / DRINK MIX metal
canisters, white/plum packaging, a white background and no flavor, health or
promotional claims. It is a fictional presentation concept, not a photograph of
a real product or an additional tested ERP packaging/BOM/compliance feature.
The fictional/synthetic disclosure remains visible on the cover.
